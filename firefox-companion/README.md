# Launch Guard Firefox companion

This extension reads only visible public cards on `j7tracker.io` and sends them to `http://127.0.0.1:8787`. It does not read cookies, passwords, wallet keys, browser history, or hidden session data. It cannot click Deploy.

For a temporary local installation, open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on**, and select `manifest.json` in this folder. Keep J7 open and signed in.
