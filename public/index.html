Agent connections

AI reviews public X posts and prepares original coin concepts. Market fee numbers are estimates, and they do not confirm cash received.

  • AI provider: OpenAI API using structured JSON responses.
  • J7 discovery: the Firefox companion reads the signed-in feed.
  • J7 browser mode: browser drafts use your signed-in Firefox page and need no session token. You review and submit each launch in J7.
  • J7 API token: optional for the separate direct API route.
  • Spending guard: launch caps and the SOL reserve are set in the private local configuration.
  • Wallet secrets: never paste a raw private key or seed phrase.
Discovery can run unattended. Creator fees are estimates, and token launches can lose funds. Review each idea and cost before any live transaction.
